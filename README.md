# AuthCard-By-Hexky

Form login & register dengan efek **3D tilt**, **spotlight ngikutin kursor**, dan **shimmer**. Pure HTML, CSS, JS - tanpa library, tanpa build step.

---

## 🔗 Live Preview

Coba langsung tanpa perlu install apa-apa di sini: 
**[hexkyauthcard.vercel.app](https://hexkyauthcard.vercel.app)**

---

## ✨ Kenapa bikin ini?

Iseng. Bosen lihat form login yang datar dan ngebosenin. Jadi coba bikin card yang ada dimensinya dikit — miring ngikutin kursor, ada cahaya yang gerak, ada kilau lewat. Ternyata hasilnya lumayan, jadi saya rapihin dan taruh di sini.

---

## 🚀 Fitur

| Fitur | Deskripsi |
| :--- | :--- |
| 🎴 **3D Tilt & Parallax** | Card miring ngikutin gerakan kursor |
| 🔦 **Spotlight** | Cahaya ngikutin posisi mouse |
| ✨ **Shimmer** | Kilau lewat saat hover |
| 🔄 **Login & Register** | Satu halaman, transisi smooth |
| ✅ **Validasi Form** | Error merah + card goyang kalau salah |
| 👁️ **Toggle Password** | Tombol mata buat lihat password |
| 💬 **Tooltip Custom** | Tooltip yang muncul pas hover |
| 🔔 **Toast Notif** | Notifikasi muncul di pojok |
| 📱 **Responsive** | Rapi di desktop & mobile |
