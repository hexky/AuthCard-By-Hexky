# AuthCard-By-Hexky

Form login & register dengan efek 3D tilt, spotlight ngikutin kursor, dan shimmer. Pure HTML, CSS, JS. Tanpa library, tanpa build step.

## Kenapa bikin ini?

Iseng. Bosen lihat form login yang datar dan ngebosenin. Jadi coba bikin card yang ada dimensinya dikit — miring ngikutin kursor, ada cahaya yang gerak, ada kilau lewat. Ternyata hasilnya lumayan, jadi saya rapihin dan taruh di sini.

## Fitur

- 3D tilt + parallax
- Spotlight ngikutin mouse
- Shimmer pas hover
- Login & register satu halaman, pindahnya smooth
- Validasi form (error merah + card goyang)
- Tombol mata buat lihat password
- Tooltip custom
- Toast notif
- Responsive
